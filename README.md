# 🤟 ALFALIBRAS

Aplicativo educacional que utiliza **visão computacional** e **machine learning** para auxiliar no aprendizado do alfabeto em **LIBRAS** (Língua Brasileira de Sinais).

> ⚠️ Versão **alpha** em desenvolvimento. Atualmente reconhece apenas as vogais **A, E, I, O, U**.

---

## 🎯 O que é

O ALFALIBRAS é um software educacional que captura a imagem da webcam do usuário, detecta a mão através do **MediaPipe** e classifica o sinal apresentado utilizando um modelo de machine learning.

A aplicação possui uma interface gráfica desenvolvida com **PySide6**, com modos de **aprendizado** e **teste** para cada vogal.

---

## 🎮 Como funciona

1. **Aprender**: Veja exemplos visuais da letra — imagem da letra, sinal em LIBRAS e posicionamento da mão
2. **Praticar**: Tente reproduzir o sinal mostrado nas imagens de referência
3. **Testar**: Ative a câmera e faça o sinal em frente à webcam
4. **Feedback**: O app indica se o sinal foi reconhecido corretamente
